1. Extract local Figma variables by clicking Extract Variables.
  2. When extraction is successful and ready, click Download Variables, which will trigger the download interface.
  3. To update qm-design-system with these changes, run
    pnpm sync:tokens at the root of the repository.
Download Variables

Note: Downloaded file will be named figma-tokens.json, set to save in the Downloads folder by default. Renaming the file or changing the destination folder will require you to specify the filepath with the
--file=<filepath> flag when running the sync command in qm-design-system.
