# Typography

Text styles are synced from Figma's text styles and applied as a single utility class, which sets font family, size, weight, line height
and letter spacing together. A Figma text style maps to its class by name: `text/header/h4` → `type-header-h4`.

- **Header** styles for headings and display text
- **Body** styles for running text
- **UI** styles for labels, buttons and form controls
- **Link** style for inline links
