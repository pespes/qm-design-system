# Quartermaster Design System

`@quartermaster-inc/ui-components` is the React component library that powers Quartermaster product UIs. Components are built on
[BaseUI](https://base-ui.com) and [Shadcn](https://ui.shadcn.com), and styled with Tailwind v4 using design tokens from
`@quartermaster-inc/ui-tokens`, which are synced directly from Figma.

## Getting Started

Install the package:

<Source language='bash' dark code={`pnpm add @quartermaster-inc/ui-components`} />

Import the token and component stylesheets into your app's main stylesheet, in this order:

<Source
  language='css'
  dark
  code={`@import '@quartermaster-inc/ui-tokens/css/tokens';
@import '@quartermaster-inc/ui-tokens/css/tokens-pro';
@import 'tailwindcss';
@import '@quartermaster-inc/ui-components/styles.css';`}
/>

Then import components by name:

<Source
  language='tsx'
  dark
  code={`import { Button } from '@quartermaster-inc/ui-components';

<Button variant="brand">Get started</Button>`}
/>

## Brand Themes

The Homeowner brand is applied by default. Wrap any part of the tree in `data-theme="pro"` to switch its children to Pro brand colours,
with no extra classes needed. Use the **Select Brand** toolbar option to preview stories in either theme.

<Source
  language='tsx'
  dark
  code={`<Button variant="brand">I am a green button</Button>

<div data-theme="pro">
  <Button variant="brand">I am a blue button</Button>
</div>`}
/>
