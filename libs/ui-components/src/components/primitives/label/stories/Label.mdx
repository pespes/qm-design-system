## Accessibility
The Label component is to be paired with a form control element (ie. `<button>`, `<input>`, `<select>`, etc). In order to correctly pair the label to the form control element,
use the `htmlFor` attribute, with the form element’s id as the value. Refer to story [Disabled by Sibling](#disabled-by-sibling) for example of the `htmlFor` attribute in use.
