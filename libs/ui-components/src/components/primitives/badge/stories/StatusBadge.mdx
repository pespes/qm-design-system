## Usage
A `<StatusBadge/>` communicates the current state / condition of an item with the use of colour and a label to convey meaning
at a glance. Labels should be concise and meaningful, without requiring the user to dig into further details for understanding.
As these indicators are not assigned `role=status`, a `<StatusBadge>` should not be used to indicate live state changes, such
as a form submission. See Alert or Toast for more details.
