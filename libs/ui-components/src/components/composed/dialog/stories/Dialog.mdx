## Usage
This component is replacing the `qm-ui` `<Modal/>` component, with some key architectural differences noted below.
#### Integrated vs External Trigger
By default, the `<Dialog/>` component is controlled, allowing devs to pass in `open` and `onOpenChange` props to handle
the open / close state of the dialog from anywhere in the codebase. onOpenChange handles both the opening and closing of the dialog.
In siutations where the sole trigger for the `<Dialog/>` lives the same file as its definition, devs can pass a `<Button/>` into the
`triggerBtn` prop, which allows BaseUI to internally manage the Dialog's open / closed state.
Note that you can have the internal `triggerBtn` prop, and also still pass `open` and `onOpenChange` props to the Dialog for
other onOpenChange events, such as the closing of the Dialog from a footer button.

#### ClosesDialog on Footer Buttons
If either of the `primaryFooterBtn` or `secondaryFooterBtn` has the property `closesDialog={true}`, BaseUI will internally
handle the closure of the Dialog, no onClick function necessary. However, an onClick event can be provided if other events
should fire on button click as well, and BaseUI will fire all events in tandem. One caveat to note is that the close event
will fire immediately, without waiting for any requests still in flight. Delaying the closure until requests are completed
requires an onClick function to be passed that also handles the closure of the Dialog.

*Note that the footer buttons now accept a JSX `<Button/>` instead of an object of button props.*

#### onOpenChangeComplete
Fires only after the open or close animation of the dialog completes. When closing a dialog, this is ideal for resetting content
to prevent any flicker on close.

## Accessibility
When the Dialog is opened / closed by an external trigger, it is best practice for the button to include the attributes
`aria-haspopup: dialog` and `aria-expanded: true / false` to match the open state of the dialog. When a Button is passed
in as a `triggerBtn` prop, these attributes are automatically applied to the button.
