## Usage
The RadioGroup allows for either vertical or horizontal orientation, but vertical should be the preference in most use cases,
particularly if there are a lot of options in the `options` array.

## Accessibility
- **Labelling**: This element does not include a label component for the group. When using `<RadioGroup>`, create a sibling label element and use `aria-labelledby`. Refer to the [Group Label Example](#with-group-label) story for an example.
