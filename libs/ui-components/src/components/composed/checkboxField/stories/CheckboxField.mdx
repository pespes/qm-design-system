## Usage

The `<CheckboxField/>` component wraps a `<CheckboxGroup/>` with a *required* label, and optional description, error messaging, and validation support in a `<fieldset/>` to create an accessible form field.
A single or an array of errors (`Array<string | { message: string}>`) may be provided to the component, all of which will render. Any error present will mark individual checkboxes as `aria-invalid`, as seen the [Invalid example](#invalid)

For more information about the CheckboxGroup state management, visit the `<CheckboxGroup/>` page, and visit the `<Checkbox/>` page for information on individual checkbox components.


## Accessibility

- **Screen Readers** — The legend has `aria-labelledby` connecting to the CheckboxGroup, and `aria-describedby` to include the description and any error messages (in that order).
- **Disabled State** — A disabled CheckboxField applies `aria-disabled` to all checkboxes to prevent selection. Checkboxes can be individually disabled as well by passing the `disabled` prop directly to one.
- **Required** - CheckboxField does not support `aria-required`, as assigning it to individual checkboxes would suggest all checkboxes should be selected. Error messaging and validation can help communicate that a selection is required upon form submission.
